About

I'm a QA automation and performance engineer based in Mumbai, with 8+ years across logistics, insurance, financial services and SaaS. I design automation frameworks that stay maintainable as products grow, and I test the parts users never see: APIs, data integrity and behaviour under load.

My core stack is Playwright, Selenium, Karate, Postman and JMeter, wired into CI/CD with BrowserStack, Jenkins, Azure DevOps and GitHub Actions. For performance work, I build workload models based on Little's Law and diagnose bottlenecks with Grafana, Dynatrace and AWS CloudWatch alongside DevOps teams.

I've led QA teams, set automation standards and mentored junior engineers. These days I also use AI-assisted testing (Claude, GitHub Copilot and Playwright MCP) to develop tests faster and widen scenario coverage. I'm ISTQB® certified at Advanced Test Manager level and in AI Testing.
